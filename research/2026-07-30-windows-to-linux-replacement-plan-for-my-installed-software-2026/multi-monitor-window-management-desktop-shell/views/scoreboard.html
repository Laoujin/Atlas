Full time · decision

Pick KDE Plasma 6.7 on Wayland

It is the only desktop that natively covers per-monitor panels, per-screen wallpaper, arbitrary fractional scaling, per-screen ICC profiles usable together with HDR, and — new in 6.7, after 21 years of requests — per-screen virtual desktops [1][2]. FancyZones comes back as PlasmaZones ⭐ 296 [3].

WHAT IT COSTS  →  Fences has no equivalent, that workflow disappears [8] · DisplayFusion's monitor-splitting and one-click window profiles degrade to scripts · X-Rite becomes copied factory .icm files plus ArgyllCMS, with no VCGT loading on Plasma Wayland [34]

Points reward capability coverage, not workflow continuity. Read the tiling column as "different game, played well" rather than "nearly the same desktop".
RED CARD · POSSIBLE ABANDONMENT

Legion hybrid graphics: the dGPU owns every external output

On many Legion models the internal panel is driven by both GPUs, but every external output — HDMI and USB-C alike — is wired to the NVIDIA GPU only, and hybrid mode has produced blank external displays [46].

A long-standing report has mutter failing to initialise the dGPU and falling back to CPU rendering specifically when a secondary screen is attached to it, while single-display hybrid works fine [44]. NVIDIA's own forums carry the same complaint for KDE, GNOME and Cinnamon [45], and Legion "Hybrid (iGPU only)" BIOS modes cause problems of their own [47].

BEFORE COMMITTING → boot a live Plasma 6.7 image with the external monitor plugged in, and test all three BIOS graphics modes. This is the one item on the list that can be a hard blocker rather than an inconvenience.
Rule change · effective October 2026

X11 is relegated. Choose Wayland now.

Plasma 6.7 is the last release with an X11 session [4] and 6.8 drops it [5], with more than 95% of Plasma 6.6 users already on Wayland [6]. Two of the pieces you need — PlasmaZones and per-screen colour management — are Wayland-only anyway [3][35].

Transfers out · four Windows shirts returned

Who leaves, and who replaces them

Outgoing · DisplayFusion 12.1.1

DisplayFusion [7]

In: Plasma panels + kscreen / kscreen-doctor + PlasmaZones ⭐ 296 + RememberWindowPositions ⭐ 246

Taskbars, per-monitor wallpaper, hotkeys and monitor profiles all land. Lost: monitor splitting, TitleBar buttons, and Triggers — the window-created / desktop-unlock event scripting [7].

~80% · FOUR PIECES
Outgoing · Stardock Fences 6

Fences [8][9]

In: nothing that plays the same position. Folder View widgets are a genuine Folder Portals equivalent [20]; DING stacks group by type [21][23].

No automation rules, no roll-up, no Peek — and users report you cannot even hand-order icons inside a Folder View [24]. Grouping by file type is not grouping by intent. The realistic migration is to stop using the desktop as a filing system.

NO EQUIVALENT
⊞
Outgoing · PowerToys FancyZones 0.97.1

FancyZones

In: PlasmaZones ⭐ 296 on Plasma 6.4+ Wayland [3], or Tiling Shell ⭐ 2.0k on GNOME [12]

KDE's built-in editor alone is not enough — it cannot store multiple layouts [11]. PlasmaZones adds per-monitor and per-virtual-desktop layouts, which FancyZones never had.

FULL · ARGUABLY BETTER
◐
Outgoing · X-Rite Color Assistant 2.57

X-Rite Color Assistant [10]

In: the factory .icm files copied to /usr/share/color/icc and assigned per screen; recalibrate with ArgyllCMS + DisplayCAL / displaycal-py3 ⭐ 1.6k [31][32]

Color Assistant is a profile loader, not a calibrator — it only restores Lenovo's factory sRGB / Rec.709 / HDR profiles [10]. There is nothing to port, just the files. Copy them off before you wipe the partition.

PROFILES YES · VCGT NO
▤
Outgoing · NVIDIA Control Panel / NVIDIA App (display side)

NVIDIA display config

In: System Settings → Display — resolution, refresh, HDR, VRR, per-monitor scaling

nvidia-settings is largely inert under Wayland; the desktop owns display config. KWin auto-enables VRR for fullscreen apps, and unlike X11 multiple monitors do not break G-Sync [48].

FULL · DISPLAY SIDE
Signings · the squad you assemble

Nine pieces, one desktop

Marquee signing · zone tiling

PlasmaZones

⭐ 296

Drag-to-snap tiling as a KWin effect: 26 built-in layouts, per-monitor, per-desktop and virtual-screen. Plasma 6 on Wayland only [3].

Window memory

RememberWindowPositions

⭐ 246

Restores position, size, screen and virtual desktop per application on Plasma 6+. Caption matching at 85% misfires on titles with counters, and its Session Restore interaction is unofficial — it has caused crash loops [27].

Output profiles (non-KDE)

kanshi

⭐ 718

The standard hotplug profile switcher — and it can blank the laptop panel when docked [29][50]. Inside KDE, kscreen already keys config to the connected-output set.

Calibration

displaycal-py3

⭐ 1.6k

The maintained Python 3 fork of DisplayCAL, targeting Python 3.9+ [32]. ArgyllCMS underneath supports the X-Rite / Calibrite i1 Display line with vendor corrections [31].

GNOME taskbar

Dash to Panel

⭐ 4.4k

A Windows-style panel for GNOME with per-monitor and per-workspace isolation — the only route to a real taskbar on that shell [15].

GNOME zones

Tiling Shell

⭐ 2.0k

Layout editor and snap assistant, multi-monitor with differing scale factors, GNOME 42 through 50 [12][13].

Spanned wallpaper

Superpaper

⭐ 1.3k

The only real answer to one image across all monitors, but its supported-DE list is rooted in X11-era tooling [18].

Desktop icon groups

Folder View widgets

built in

As many as you like on the desktop, each pointing at a different folder, filtered by regex or file type [20]. Two or three for the folders you actually touch, and a launcher for everything else.

Free agent · a different game

niri

⭐ 26.5k

Multi-monitor as core design from the start, mixed DPI working, all its own UI pixel-perfect under fractional scaling — and no documented colour management [49].

Colour room · the X-Rite handover

Profiles land. Gamma curves do not.

SHARP EDGE · VCGT ON WAYLAND

The protocol picture is finally good. color-management-v1 merged upstream in February 2025 after five years and 800+ review comments, covering ICC profiles and HDR for colour-aware and unaware clients alike [37]. KWin has assigned per-screen ICC profiles since 2023 [35], and Plasma 6.7 removed the last compromise: an ICC profile while HDR is active [1][36]. GNOME 50 shipped wp_color_management v2 plus HDR screen sharing [38].

The regression is the video-card gamma table. Plasma on Wayland exposes no API to set VCGT, so calibration curves are never loaded into the GPU LUT — the correction has to live in the profile and be applied by the colour-management system instead [34]. A 2026 walkthrough of the whole loop flags the same trap: applying an ICC profile only inside a colour-managed app is insufficient, because that app will not set the VCGT tables [33].

For a factory-profile-loading workflow that is acceptable. For hardware-calibrated grey tracking it is a real loss versus Windows.

Unavailable for selection

Four things that do not come back

01

Fences' automation, roll-up and Peek

Shaded groups that sort new files by rule, collapse to a title bar, and float above every window on Win+Space [8].

02

DisplayFusion splitting, TitleBar buttons, Triggers

No compositor exposes one physical monitor as several virtual ones, and there is no event-scripting layer for window creation or desktop unlock [7].

03

Hardware VCGT loading

Calibration curves cannot be pushed into the GPU LUT on Plasma Wayland [34].

04

Guaranteed window restore across dock / undock

XDG Session Management shipped in wayland-protocols 1.48 on 1 Apr 2026 and KWin implements it — but KDE is explicit that the remaining gate is toolkit and app adoption [25][26].
