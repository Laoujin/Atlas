⚠ Fine print — read before checkout

Fractional scaling is still being finished in public: 6.3 snapped UI elements to the pixel grid, 6.4 stopped auto-picking blurry “almost-1×” factors, and 6.6.4 was still clearing fractional-scaling shadow and tooltip regressions. [32] 6.7 adds the still-experimental xx-fractional-scale-v2 protocol so windows stop leaving hairline gaps on HiDPI. [33]

Remote desktop into this unit shares an already-logged-in session only: KRDP has no headless support and no immediate plans, because SDDM cannot do it yet. [28]

NVIDIA owners: explicit sync needs driver 555.58+, XWayland 24.1+ and KWin 6.1+ [29], and even on the 580 series users report Plasma Wayland freezes and fd leaks. [30]

The X11 session included with 6.7 is the last one ever shipped and is maintained only until early 2027. [5]

⚠ Fine print — the extension tax

There is no built-in taskbar, tray or dock-with-window-buttons. Getting them means extensions, and extensions are third-party JavaScript pinned to a shell version. On the GNOME 50 upgrade, popular system extensions including dash-to-dock and appindicator support were simply deactivated because they had not been updated. [34]

Zorin users hit a shell update on 1 Jul 2026 that left every system extension stuck in INITIALIZED with canChange=false. [35]

The structural cause is worse than slow developers: extension review on extensions.gnome.org runs through one person, and in spring 2026 that reviewer lost reliable internet access for geopolitical reasons while the queue climbed to nearly 500 submissions — many of them one-line compatibility bumps. [3]

Global hotkeys — push-to-talk, screenshot keys, clipboard tools — do not work: GNOME 50 has no functional GlobalShortcuts portal backend. [2]

03

Professional series — three-pack

All Wayland-only, none of them hands you a discoverable desktop. Not a first login: as a Windows switcher you would be relearning window management, the panel, the launcher, notifications and display config in one week.

Month three, not day one

Tiling compositors

No start menu, no taskbar, configuration is a text file. Windows-11 familiarity rating: zero out of five, by design. Add one as a second session once the first desktop is boring.

niri

⭐ 26k · scrollable tiling · laptop-first

One infinite horizontal strip per workspace instead of a split grid. Friendliest of the three to reason about, and gesture-native. [23]

Unfamiliar mental model Smaller dotfiles ecosystem

Hyprland

⭐ 38k · dynamic tiling · animations, blur

Most popular of the set and the best-looking; also the fastest-moving, so config churn is on you. [22]

Fastest churn Occasional rough edges

Sway

⭐ 17k · i3 semantics · lowest overhead

Rock-solid and predictable, but the wlroots portal stack is where 2026's gaps concentrate. [21]

No GlobalShortcuts backend No XWayland scaling Single-window sharing broken

⚠ Fine print — whole three-pack

On the wlroots stack, every X11 app is blurry on a fractionally-scaled output, the whole monitor shows up as one shareable “window”, Chrome's GPU process can die after a resize, and DisplayPort MST tiled monitors appear as two screens. [21] Clipboard history needs a compositor-aware tool such as cliphist ⭐ 1.5k. [27]

Worth knowing before you buy the bundle: KWin already has built-in custom tile layouts and edge-snap zones, which covers most of what a Windows FancyZones user actually wanted.

⚠ Chart notes

Electron apps such as Slack may need --enable-features=WebRTCPipeWireCapturer and show a redundant duplicate share picker. [24] Zoom's long-standing bug: the first share works, the second gives a black screen — Teams as a browser PWA beats the native client here. [25]

Wine apps get pointer-location bugs on multi-display setups; the 2026 consensus is that Wayland on AMD or Intel is a non-event, and NVIDIA is where the remaining stories come from. [31]

On resource use, treat the ordering as reliable and the magnitudes as noise. One 2026 round-up puts XFCE ~1.36 GB, Cinnamon ~1.89 GB, GNOME ~2.10 GB and Plasma ~2.67 GB of total system usage [15]; a per-desktop measurement that subtracts base-system overhead puts all four within ~60 MB of each other. [20] Different methodologies, same ranking. On a dev machine with 16 GB or more this axis should not decide anything.

The reassuring number in the whole catalogue: over 95% of Plasma 6.6 users are already on Wayland. [13] Wayland is not the risky choice any more; it is the only choice, and it mostly works.

05

Returns & exchanges

Some models come off the shelf and go back on it. Three of them are welded to the box they shipped in.

Exchange at the login screen

No reinstall · package install + session picker

  • GNOME, KDE Plasma, XFCE, Sway, Hyprland, niri on Fedora, Ubuntu/Debian, Arch and openSUSE. Install the second desktop, log out, pick it from the greeter, switch back if you hate it.
  • ⚠ The cost is clutter, not risk: installing both GNOME and Plasma pulls in two app stacks and two sets of settings daemons, and your app menu doubles in size.

Non-returnable — bundled with the distro

Changing your mind means a reinstall

  • Cinnamon → Linux Mint. Mint is Cinnamon's upstream. [40]
  • Zorin desktop → Zorin OS. The layouts are the product; there is no other home for them. [44]
  • COSMIC → Pop!_OS, softening. Still System76 turf, but the Fedora spin plus Arch/openSUSE/NixOS packages make this the weakest lock-in on the list. [41] [42]
  • “I need a real X11 session” → Mint or an XFCE distro. The sneaky one. It is not a desktop preference, it is a distro constraint, because GNOME has already removed X11 [6] and Plasma removes it in October 2026. [5]

Practical consequence: choose the distro on release model and hardware support, and the desktop second — unless your desktop is one of the four above, in which case the desktop chose for you.

06

Warranty exclusions

Two conditions to settle before you install anything. Neither is a desktop defect; both change which desktop you should buy.

⚠ If the machine has an NVIDIA GPU

This is your dominant risk, not your desktop choice. Confirm driver 580-series or later and expect to read a forum thread or two. Explicit sync needs driver 555.58+, XWayland 24.1+ and KWin 6.1+ [29], and freezes are still reported on 580. [30] AMD or Intel graphics make Wayland a non-issue. [31]

⚠ If you need to RDP into this machine

Plausible for a homelab owner, and it flips the recommendation. GNOME Remote Desktop supports headless and pre-login remote login through GDM with hardware-accelerated encoding; KRDP requires an already-logged-in session and has no headless plans. [28] [17] If that is a hard requirement, run GNOME on that box or plan on SSH plus tooling that needs no forwarded display.
