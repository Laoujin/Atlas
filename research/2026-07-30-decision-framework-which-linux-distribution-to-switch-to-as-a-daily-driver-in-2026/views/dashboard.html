The one branch that flips the answer

Ubuntu 26.04 LTS carries the NVIDIA 595 driver in-archive, installed by one command — ubuntu-drivers autoinstall [55] — and ships five years of security maintenance [2]. On an NVIDIA machine that buys you more than Fedora's fresher userspace does. Fedora's path works but generates a local MOK key by hand under Secure Boot [28], and the atomic images deadlock outright.

CONFLICT desktop-choice ⇄ distro-landscape + toolchain-fit 01 / 03

The desktop you want is not the flagship of the distro you want

desktop angle says
KDE Plasma — the only session where Windows muscle memory, working global hotkeys and sane mixed-DPI scaling coexist
⇄
other six angles say
Fedora or Ubuntu — and both ship GNOME 50 by default

2026 removes the fallback. GNOME 50 deleted its X11 session outright — roughly 27,540 lines cut from Mutter, and you cannot log into an X11 GNOME session even with Xorg installed [8]. Plasma 6.8 drops its own X11 session on 14 October [9]. There is no "just use X11 if Wayland misbehaves" branch left — only a choice of which compositor's rough edges you accept. KDE is also effectively the only desktop with a working GlobalShortcuts portal backend [41].

resolution Swap the edition, not the distro. Fedora KDE Plasma Desktop is an official edition on Plasma 6.6.4 [10] — Kubuntu and Aurora ⭐ 749 are the equivalents on the other two tracks [11].
CONFLICT release-model ⇄ windows-migration 02 / 03

Your snapshots fight your file sync

release-model angle says
Configure btrfs snapshots on install day — neither Fedora nor Ubuntu does it for you
⇄
migration angle says
Dropbox's Linux client syncs only to unencrypted ext4

Nothing else in the run surfaces this collision. The rollback advice is sound in isolation: Fedora's default installer doesn't produce a snapshot-friendly btrfs layout, and pre/post snapshots need packages installed by hand [12]. The sync constraint is equally real — the client depends on extended attributes and refuses everything but plain ext4 [13]. Follow both angles literally and a btrfs-everywhere install silently costs you Dropbox.

resolution btrfs for / and /home, plus one dedicated unencrypted ext4 partition that holds only the sync folder. Decide this at partitioning time — it is the one choice you cannot defer.
CONFLICT upkeep-ranking ⇄ toolchain-fit 03 / 03

Atomic is simultaneously the lowest-upkeep and the highest-friction option

upkeep angle ranks it
#1 — a bad update is undone by rebooting into the previous image
⇄
toolchain angle ranks it
last — layering is discouraged and IDEs expect a mutable host

Both readings are correct about the same system. Atomic derivatives stage every update as a new deployment and always keep a rollback deployment [14], and Bluefin ⭐ 2.6k explicitly frames your relationship as being with Flathub and Homebrew rather than with a distro. But layering docker-ce on an image-based Fedora still means placing a .repo file by hand, against community advice [70].

reconciles only if You accept container-first development — Toolbx/Distrobox for the SDKs, the host image left untouched. Bluefin DX bakes in Docker Engine with Compose and Buildx for exactly this [24].
fails outright if Your GPU is NVIDIA. A May 2026 Fedora Kinoite 44 update deadlocked on an akmod dependency conflict during a kernel bump [15] — the one failure mode the "just reboot to roll back" promise doesn't cover.

⊠
wontfix · permanent

Kernel anti-cheat

Valorant, Call of Duty and Battlefield 6 are blocked by design. Across titles using anti-cheat: 17% supported, 24% running, 55% broken, 4% denied [16]. RICOCHET, Riot Vanguard and EA Javelin are the specific gatekeepers [61].

▤
wontfix · licensing

Browser DRM ceiling

Linux browsers get Widevine L3 software DRM only, capping Netflix, Prime and HBO at 720p SDR with no HDR — while HDR gaming works fine on Wayland [17].

✉
wontfix · vendor

Desktop Office & Belgian eID

Microsoft 365 desktop apps are Windows and macOS only [18]; the web build has no VBA, no add-ins, no offline [63]. And the Belgian eID cannot work through any Snap or Flatpak browser — sandbox confinement blocks the PKCS#11 module [19].

Because all three are unfixable, keeping Windows is the default — which promotes the hardware angle's Secure Boot warning from incidental to load-bearing. Microsoft's UEFI CA 2011 certificate expired 27 June 2026; distros ship dual-signed shims so Secure Boot can stay on, but BitLocker recovery is the thing that bites during partitioning [20]. Check the machine first with hw-probe ⭐ 918 [57] and a live USB.
atlas@expedition ~/linux-2026 $ cat excluded.log what the angles agreed to rule out
✗ Arch family Loses on vendor support, then loses again on June 2026's AUR supply-chain attack — a rootkit and an SSH-key stealer planted across 1,579 packages [5]. CachyOS topping DistroWatch is a page-hit ranking, not adoption [73].
✗ Pure rolling Requires reading an advisory feed before every update — Arch publishes manual-intervention notices you cannot skip [6]. That is a habit, not a setting, and it is the single upkeep cost that never amortises.
✗ Debian stable The release-model angle rules it out for a 2026 developer workstation on software age alone [37] — and Microsoft's own .NET packages have shipped broken metadata against Debian trixie [82].
▲ Linux Mint The upkeep angle's favourite, eliminated by the hardware angle. If the machine's silicon is under ~18 months old, new Intel and AMD GPU enablement lands per kernel release [21] and Mint's LTS base is too old. Mint 23 doesn't arrive until ~December 2026 [33]. Otherwise: the least-change option, Wayland fully supported [4].
